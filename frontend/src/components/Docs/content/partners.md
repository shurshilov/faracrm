Партнёры — это ваши клиенты, поставщики и подрядчики: компании и физические лица. Карточка партнёра — центр, вокруг которого собираются лиды, заказы, переписка и файлы.

## Контакты партнёра

У партнёра можно указать несколько контактов разных **типов**: телефон, email, id в мессенджере и т.д. Тип контакта определяет, как значение валидируется и как оно сопоставляется с каналами связи:

- Телефонные типы нормализуются (учитывается формат номера) — по ним входящие из WhatsApp/MAX/телефонии находят карточку.
- Идентификаторы мессенджеров (например, id пользователя бота) — сопоставляются напрямую.

> [!tip] Чем аккуратнее заполнены контакты, тем надёжнее входящие сообщения привязываются к нужному партнёру, а не создают дубли.

## Добавление контакта

В виджете контактов введите значение и обязательно нажмите «+», чтобы контакт добавился (или уйдите с поля — он добавится сам). Для лида/заказа удобно, когда партнёр уже выбран — тогда контакты привязываются к нему.

## Контроль дубликатов

Контроль дубликатов — приложение «Duplicates», оно установлено по умолчанию, отключить целиком можно на странице приложений. При сохранении имени партнёра, пары ИНН+КПП или контакта система ищет такую же запись у других партнёров. Режим каждого правила задаётся в системных настройках, ключи `constrains.*`: `block` — не дать сохранить (появится сообщение с найденной записью), `warn` — только записать совпадение в журнал сервера, пустое значение — не проверять.

По умолчанию включено одно правило: контакт партнёра (телефон, email) нельзя повторить у другого партнёра, иначе входящие сообщения привяжутся не к тому. Правила по имени, по ИНН+КПП и по контактам сотрудников выключены, включаются в настройках; `block` для имени затронул бы и автосоздание партнёров из входящих сообщений, а филиалы с одним ИНН и разным КПП — не дубли. Архивные записи не учитываются. После смены режима нужен перезапуск сервера.

## Компании и люди

Партнёр может быть компанией или человеком; людей можно привязывать к компании. Справочник «Типы контактов» (в этом же разделе) настраивает набор доступных типов, их иконки и правила формата.

## Реквизиты и банк

На вкладке **«Реквизиты»** — тип лица (физлицо, юрлицо, ИП), ИНН, КПП, ОГРН, ОКПО и юридический адрес; на вкладке **«Банк»** — БИК, банк, расчётный и корреспондентский счета.

Рядом с полями ИНН и БИК есть кнопка **«Заполнить»**: по ИНН подтянутся название, тип лица, КПП/ОГРН/ОКПО и адрес, по БИК — банк и корр. счёт. Подставленные значения можно поправить, сохраняется запись как обычно.

Данные берёт модуль **DaData** (установлен по умолчанию): в системных настройках задайте ключ `dadata.api_key` из личного кабинета dadata.ru. Подсказки бесплатны до 10 000 запросов в сутки. Без ключа кнопка подскажет, что его нужно указать.
